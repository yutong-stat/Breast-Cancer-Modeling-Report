# Breast Cancer Diagnosis Classification

Statistical learning analysis of the Wisconsin Diagnostic Breast Cancer dataset using logistic regression, PCA, LDA, lasso logistic regression, and elastic net logistic regression.

## Reports

- [HTML report](https://yutong-stat.github.io/Breast-Cancer-Modeling-Report/)
- [PDF report](Breast%20Cancer%20Modeling%20Report.pdf)
- [R Markdown source](Breast%20Cancer%20Modeling%20Report.Rmd)

## Main result

Elastic net logistic regression gave the strongest overall performance, with test accuracy 0.971, sensitivity 0.937, specificity 0.991, and AUC 0.992.
